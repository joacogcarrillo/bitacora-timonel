# Acceso a Bitácora

Dirección compartible: https://joacogcarrillo.github.io/bitacora-timonel/

Página estática que redirige a la aplicación de turnos. Si el navegador bloquea
la redirección, conserva un enlace para entrar. Funciona sin JavaScript.

Este repositorio público contiene solo el acceso. La aplicación y su planilla
se administran por separado; acá no se guardan nombres ni reservas.

GitHub Pages publica la raíz de `main`. Para cambiar el destino, actualizar
ambas URLs de `index.html`, subir el commit y verificar el destino desde el enlace
compartible. Conservar el destino anterior en el historial permite volver atrás.
